01 / iOS

NASA Explorer

A SwiftUI app for discovering NASA’s Astronomy Picture of the Day and exploring space imagery from NASA’s media library.

Problem

NASA provides multiple public APIs, but their content is spread across different services and can be difficult to explore from one mobile experience.

Solution

Built a polished iOS app that combines NASA’s daily astronomy content, searchable media library, detailed image views, and saved discoveries in one accessible experience.

Architecture

Built with SwiftUI and MVVM. Observable view models manage UI state, service types handle networking, Codable models represent API responses, and SwiftData provides local persistence.

Technical challenges

Integrated two NASA APIs with different response structures, handled image and video APOD content, decoded nested JSON, managed asynchronous loading states, and displayed remote media reliably.

Tradeoffs

Used AsyncImage for straightforward remote-image loading and SwiftData for lightweight on-device persistence. More advanced image caching and offline synchronization are planned improvements.

Results

Delivered a reusable, API-driven SwiftUI application with clear separation of concerns, persistent saved content, responsive loading states, and a polished space-inspired interface.

Key features
  • NASA Astronomy Picture of the Day
  • Searchable NASA image library
  • Category-based space exploration
  • Detailed and full-screen media views
  • Saved discoveries with SwiftData
  • Loading, empty, and error states
